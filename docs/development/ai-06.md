# AI-06: Hybrid Retrieval and Complete-Source Processing

Status: approved for local implementation; not implemented yet.
Owner decisions: 2026-10-25. No application activation or real provider calls.

## Scope

All active owned pages and extractable materials are indexed asynchronously. Explicit
request scope remains authoritative. Calendar and database properties use existing
structured reads; page-backed record content participates as ordinary pages.
Use the pinned local AI-05 embedding provider, versioned chunks, deterministic
lexical/vector fusion and PostgreSQL exact vector search first. No new service,
reranker, ANN index, OCR or bookmark fetching. Preserve ordinary search APIs.

PDF pages/PPTX slides use actual extraction locations. DOCX/plain text use ranges.
Derived publication requires current owner/source/version. Trash/access loss hides
content immediately. Leased jobs recover from restart; old workers cannot publish.

Option 2B processes complete available source text automatically in model-sized
steps with persisted progress, cancellation and restart. Track versions/ranges and
combine results with provenance; never claim all original visual content was read.
A comparison of current lecture notes and lecture slides is an acceptance scenario.
Do not implement subscriptions, paywalls or user request/token/document quotas.
Retain technical validation, finite retries and resource admission; retain the
unlimited policy seam and usage ledger for future product decisions.
